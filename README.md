# Auréa

Auréa is a luxury jewelry landing page concept built with HTML, CSS, JavaScript, and Three.js. The project combines elegant visual design with interactive 3D bracelet models to create a premium digital showroom experience.

## Features

* Interactive 3D bracelet rendering with Three.js
* Responsive design for mobile, tablet, and desktop
* Smooth scrolling navigation
* Luxury-inspired typography and color palette
* Product selection integrated with the commission form
* Lightweight, dependency-free frontend (except Three.js)

## Technologies

* HTML5
* CSS3
* JavaScript (ES Modules)
* Three.js

## Running Locally

Clone the repository:

```bash
git clone https://github.com/your-username/aurea.git
cd aurea
```

Start a local server:

```bash
npx serve
```

or

```bash
python -m http.server
```

Then open the local address provided by your server.
